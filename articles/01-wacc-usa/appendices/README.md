# Paper 1: electronic appendices

These are the electronic appendices to Paper 1, version 2.2 of 26.10.2026. The paper's text links to this folder. The appendices are in Russian, the language of the paper.

Each appendix is a separate file, and `appendices-all` combines all of them. Every appendix comes as PDF and as Word (.docx). Each file has its own reference list.

Letters follow the Russian alphabet as used in the paper. File names transliterate the letters per GOST 7.79-2000, system B.

Page counts refer to the PDF files. `SHA256SUMS` lists the checksums of all files in this folder; to verify them, run `sha256sum -c SHA256SUMS`.

The appendices contain derived series and results only, such as annual returns, averages, premia and intervals. They contain no vendor price levels.
